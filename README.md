# 📋 Advanced Task Manager

A sleek, modern task management application with a beautiful dark/light theme interface. Organize your tasks efficiently with kanban boards, calendar views, and productivity analytics — all in one place.

---

## 👩‍💻 Developed By

**Akanksha Bursu**

---

## ✨ Features

- **Kanban Board** - Drag and drop tasks between columns (To Do, In Progress, Done)
- **Calendar View** - Visualize tasks scheduled by date
- **Dashboard** - Analytics and completion statistics with priority charts
- **Pomodoro Timer** - Built-in focus timer with customizable intervals
- **Voice Input** - Add tasks using voice commands
- **Dark/Light Theme** - Toggle between themes
- **Import/Export** - Backup and restore data with JSON files
- **Local Storage** - Data stays safe in your browser, no signup needed

---

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- Local Storage API
- Web Speech API
- Canvas API

---

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/sweetylearner-max/Advanced-TaskManager.git
   ```
2. Open `index.html` in your browser — no installation needed!
